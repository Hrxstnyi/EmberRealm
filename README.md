# 烬域：卡拉比亚战区 (EmberRealm)

> 现代战区策略游戏 | UE5 + C++ | 三阶时间流速 · 阵营制衡 · 经济战争闭环

## 游戏概述

《烬域：卡拉比亚战区》是一款现代战区策略游戏，灵感来源于桌游规则全书。与《文明》系列的"从远古到未来"4X玩法不同，本作聚焦于**现代局部战区**的策略博弈：

- **三阶动态时间流速**：非战时（季度）→ 战时（周）→ 战役（四小时），战局节奏随冲突强度自动切换
- **三大阵营制衡**：戍卫军（阵地防守）、合约团（高速机动）、自治同盟（地形游击）
- **卡亚币经济闭环**：税收、工业开采、练兵、油耗、贸易、外交罚金
- **名誉军衔系统**：连胜晋升、连败降级、负值禁闭、判决牌Debuff
- **兵种升勋体系**：三勋封顶，每阶解锁主动/被动技能
- **六边形战区地图**：海拔机制、阵地类型、交通枢纽、资源矿区

## 技术栈

- **引擎**：Unreal Engine 5.3+
- **语言**：C++（核心逻辑）+ Blueprints（UI/关卡）
- **构建**：Unreal Build Tool
- **版本控制**：Git + GitHub

## 快速开始

### 环境要求
- Unreal Engine 5.3 或更高版本
- Visual Studio 2022（C++桌面开发工作负载）
- Git

### 编译运行
1. 右键 `EmberRealm.uproject` → Generate Visual Studio project files
2. 打开 `EmberRealm.sln`，配置为 `Development Editor | Win64`
3. 编译并运行，UE5编辑器将自动打开
4. 在编辑器中打开 `Content/Maps/BattleMap` 关卡
5. 点击 Play 开始游戏

### 使用启动器
```bash
cd Launcher
python launcher.py
```

## 核心系统说明

### 时间系统 (TimeSystem)
- 非战时：每回合推进一个季度，行动点回复6点
- 战时：每回合推进一周，行动点回复3点
- 战役：每回合推进四小时时段，行动点回复2点
- 宣战/交火自动切入战役，停火协议回归非战时

### 经济系统 (EconomyManager)
- 居民区税收：非战时35/季，战时28/季
- 铁矿：启动费60，产出120
- 石油：启动费80，产出150
- 棉花：非战时90，战时45

### 战斗系统 (CombatSystem)
- 突袭成功：敌方本回合无法反击
- 海拔修正：攻击射程差值=海拔阶数差
- 行军开火铁规：行军后不能开火，开火后不能行军
- 升勋加成：一勋+10%，二勋+25%，三勋+50%

## 胜利条件
1. **战区霸权**：掌控≥50%交通枢纽 + ≥70%资源阵地
2. **军事碾压**：全歼敌方高阶兵种+载具
3. **经济霸权**：连续两年经济收益全图第一 + 最多军事基地
