# 桌游规则审查与完善建议
## 《烬域：卡拉比亚战区｜终极完整版·官方规则全书》

**审查日期**: 2026-08-19  
**审查人**: AI合伙人  
**状态**: 已完成初步审查

---

## 1. 逻辑漏洞与不明确之处

### 1.1 时间单位不统一 [严重]
**问题**: 时序切换规则写"全域无交火、无宣战、无阵地争夺连续两日且第二日所有时段→退回战时无战役"。但三档时间单位为季度/周/四小时，"日"不是标准单位，无法精确判定切换条件。

**建议**: 统一用"回合"作为判定单位。改为"连续2回合无交火且无宣战"。各流速下的回合对应不同天数，但判定逻辑统一。

### 1.2 名誉年度清零无意义 [严重]
**问题**: 连胜2场+10名誉，连败3场-10名誉，但每年结束名誉清零。这意味着年底前名誉没有累积价值，军衔晋升（每10点一级）在清零前几乎无法触发。

**建议**: 取消年度清零，改为年度自然衰减20%。名誉作为长期资源，军衔晋升才有意义。

### 1.3 禁闭没有出口 [严重]
**问题**: 名誉负值/军衔降级触发禁闭，禁闭期间"禁止主动行军、宣战、练兵、购卡、开采、外交、获取资源"，且"无任何资源、名誉变动"。玩家无法主动从禁闭中恢复。

**建议**: 增加禁闭解除条件：
- 支付卡亚币罚金（=当前名誉绝对值×10）
- 或完成特定任务（如赢得一场防御战）
- 禁闭最长持续2回合，自动解除

### 1.4 练兵链死锁 [严重]
**问题**: 规则说"步兵需要由民兵训练，其他兵种则需要由步兵训练"，但开局只有三张练兵行动牌和一个根据地兵棋，没有初始民兵。第一步练兵无法启动。

**建议**: 开局自带2个民兵单位，或简化练兵链为"所有兵种从基地直接训练，高级兵种需要前置科技/军衔"。

### 1.5 行动牌费用歧义 [中等]
**问题**: "花费2点行动点购买一张随机行动牌，花费3点行动点可以指定购买一张3费及以下的行动牌"，但行动牌本身有1-5费梯度。购买后打出是否还要再付卡费？规则未说明。

**建议**: 明确购买即获得，打出时不再额外付费（行动点就是获取成本）。或改为"每回合行动点上限内自由打牌，牌的费用就是行动点消耗"。

### 1.6 内鬼"挑拨"判定模糊 [中等]
**问题**: 内鬼胜利条件"成功挑拨三次同盟背刺破裂"，但"挑拨"没有量化判定。是内鬼直接操作？还是间接影响？如何归因？

**建议**: 内鬼军官有隐藏行为值，执行破坏操作累积。电子游戏中可量化为：内鬼成功执行3次破坏行动（纵火、泄密、延误）且未被发现，即达成胜利条件。

### 1.7 海拔迂回无定义 [中等]
**问题**: "陆地单位无法直接进入高2阶及以上阵地（需迂回/空降）"，但迂回的路径、消耗、时间完全未定义。

**建议**: 迂回=绕路消耗额外行军时间（=海拔差×2回合），且不能经过敌方控制阵地；空降=需要航空兵+空降兵，直接落地但有被防空拦截风险（30%概率损失）。

### 1.8 经济霸权胜利时长不可控 [中等]
**问题**: "从第四年开始，连续两年经济收益全图第一"，但游戏12季度=3年保护期，意味着一局至少5年（20季度），且没有回合上限，可能无限拖延。

**建议**: 增加回合上限（默认30季度=7.5年），到时按综合分数判定。经济霸权胜利条件保留，但增加"或游戏结束时经济总分第一"的替代条件。

### 1.9 督战兵前期缺位 [轻微]
**问题**: "阵地存在督战兵→敌方无法执行俘虏操作"，但督战兵中校解锁，前中期没有督战兵时俘虏机制一边倒。

**建议**: 前期无督战兵时，俘虏成功率降低50%，且需要近战交火后才能执行。或增加基础军官的"督战"能力（效果减半）。

### 1.10 弹药补充无来源 [轻微]
**问题**: "一些兵棋单位需要弹药补充，否则无法开火"，但弹药怎么生产、怎么运输、补给线怎么建立，完全未写。

**建议**: 弹药在军事基地生产（每回合基础产量），通过补给线（道路/运输单位）输送到前线。补给线被切断则部队无法开火。这刚好和FPS炸仓库/破坏补给线联动。

## 2. 电子化适配建议

### 2.1 数据驱动设计
所有阵营、兵种、阵地、卡牌数据用DataAsset配置，便于平衡调整和模组支持。

### 2.2 事件系统
用全局事件总线处理：回合开始/结束、时间流速切换、战役爆发/结束、FPS任务完成、内鬼行为触发等。

### 2.3 存档系统
支持多存档位、自动存档、快速存档/读档。战略层数据序列化，FPS层状态按需保存。

### 2.4 AI系统
- 阵营AI：分层次决策（战略目标→区域行动→单位行为）
- 军官AI：行为树驱动，内鬼有独立行为分支
- FPS敌人AI：感知系统（视觉/听觉）、巡逻/警戒/战斗状态机

### 2.5 UI/UX
- 战略层：指挥所风格，地图为主，侧边信息面板
- FPS层：极简HUD，沉浸式
- 通用：时间流速指示器、回合进度、战报系统

## 3. 平衡性初步评估

### 3.1 阵营平衡
- 戍卫军：防守强但进攻弱，适合龟缩发育后反击
- 合约团：机动强但维护贵，适合速攻和骚扰
- 自治同盟：地形强但重火力弱，适合游击和消耗
- 初步评估：三角制衡成立，但需要数值测试

### 3.2 经济平衡
- 居民区税收稳定但量小
- 矿区产出高但需要启动费和战时减产
- 建议：增加资源价格波动机制，避免单一资源最优解

### 3.3 军事平衡
- 高阶兵种强但训练时间长、费用高
- 基础兵便宜但战力低
- 建议：增加兵种克制关系（防空克空军、装甲克步兵、反坦克克装甲）

## 5. 总结

桌游规则体系庞大、创意丰富，核心机制（三阶时间、内鬼、经济闭环）有独特价值。但存在10处逻辑漏洞需要修复，且部分机制（如卡牌、名誉军衔）在电子化时需要重新设计。建议优先修复严重漏洞，再逐步完善电子化适配。
