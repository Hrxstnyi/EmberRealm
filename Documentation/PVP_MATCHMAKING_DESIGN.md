# PVP匹配系统设计 — 特遣队介入

**版本**: v1.0  
**最后更新**: 2026-08-19  
**状态**: 设计确认

---

## 概述

《烬域：卡拉比亚战区》的PVP模式采用**双角色分离匹配**机制：策略玩家和FPS玩家分开匹配，但可以在同一局游戏中协作。核心设计目标是：
- 降低匹配门槛（策略玩家不用等FPS玩家）
- 体验边界清晰（策略玩家管宏观，FPS玩家管微观）
- 异步任务不阻塞策略回合

---

## 两种玩家角色

### 1. 策略指挥官（Strategy Commander）

**匹配方式**：策略匹配队列  
**核心体验**：回合制4X经营，管理国家经济、外交、科技、军事

**职责**：
- 管理资源、建造、研发
- 指挥大部队移动和战斗
- 发布特遣队任务悬赏
- 外交与同盟管理
- 四条胜利路线追求

**胜利路线**：
| 路线 | 条件 |
|------|------|
| 军事胜利 | 占领敌方首都 |
| 经济胜利 | 控制70%资源产地 + 卡亚币储备达标 |
| 外交胜利 | 通过同盟/吞并让所有阵营臣服 |
| 科技胜利 | 完成终极科技树 |

### 2. 特遣队指挥官（Task Force Commander）

**匹配方式**：特遣队匹配队列  
**核心体验**：第一人称精英小队作战，执行任务获得成长

**身份定位**：不是策略玩家的工具人，而是**独立的雇佣兵/特遣队首领**

**职责**：
- 从任务悬赏板选接任务（可拒绝）
- 带领精英小队执行FPS任务
- 自由行动（侦查、骚扰、拾取物资）
- 升级小队、解锁武器装备

**成长系统**：
- 完成任务获得经验和卡亚币
- 经验升级解锁武器、技能、队员
- 声望系统影响可接任务的等级和报酬

## 匹配流程

### 策略玩家开局
```
1. 策略玩家匹配 → 进入策略局（2-6人）
2. 游戏开始，策略玩家正常经营
3. 某阵营需要特种作战 → 发起"特遣队支援请求"
4. 全体策略玩家投票 → 通过则向特遣队队列发布任务
5. 特遣队玩家接取任务 → 进入FPS关卡
6. 任务完成 → 结果回写策略层
```

### 特遣队玩家匹配
```
1. 特遣队玩家排队 → 等待任务悬赏
2. 收到任务邀请 → 查看任务详情（目标、报酬、难度）
3. 接受 → 加载FPS关卡
4. 执行任务（实时，5-15分钟）
5. 完成/失败 → 结算奖励 → 返回队列
```

### 投票机制
- 发起方消耗"情报点"发起请求
- 全体策略玩家投票，半数以上通过
- 投票限时30秒，超时视为反对
- 同一阵营每回合最多发起1次

## 异步任务系统（核心）

### 设计原则
**FPS任务不阻塞策略回合**，在"后台"运行。

### 时序示例
```
策略回合1开始
  → 策略玩家A发布"炸毁敌方仓库"任务（消耗500卡亚币）
  → 特遣队玩家接取，进入FPS关卡
  → 策略玩家A继续：移动部队、调整经济、研发科技
  → 策略玩家B、C也正常操作
  → 策略回合1结束 → 回合2开始 → 回合3...
  → 特遣队玩家完成任务（现实时间8分钟）
  → 事件回写：敌方仓库被毁 → 该阵地资源减产3回合
  → 所有策略玩家收到通知
```

### 任务状态
| 状态 | 说明 |
|------|------|
| 待接取 | 已发布，等待特遣队玩家接取 |
| 进行中 | 特遣队玩家正在执行 |
| 已完成 | 任务成功，效果已回写 |
| 已失败 | 任务失败（特遣队全灭/超时/放弃） |
| 已取消 | 策略玩家取消（返还50%费用） |

### 超时处理
- 每个任务有现实时间限制（默认15分钟）
- 超时自动结算为"部分成功"（达成部分目标）或"失败"
- 特遣队玩家中途退出 → 任务失败，策略玩家返还30%费用

## 任务类型

### 进攻类
- **炸毁设施**：仓库、雷达站、桥梁、电厂
- **刺杀目标**：敌方军官、科学家、政治人物
- **突袭基地**：摧毁敌方军事设施，缴获物资

### 侦查类
- **敌后侦查**：获取敌方部队部署情报
- **窃取文件**：获得科技情报或外交机密
- **标记目标**：为炮兵/空军指引目标（增加命中）

### 救援类
- **营救战俘**：救回己方被俘军官
- **护送要员**：保护VIP到达安全区
- **撤离平民**：减少民心损失

### 自由行动（无悬赏）
- 特遣队玩家可在敌后自由探索
- 拾取散落物资（弹药、武器、情报）
- 骚扰敌方补给线（小额破坏）
- 获得少量经验和资源

## 战果回写机制

FPS任务的结果通过事件总线回写到策略层，产生持续影响：

| 任务结果 | 策略层影响 | 持续时间 |
|---------|-----------|---------|
| 炸毁仓库 | 该阵地资源产出-50% | 3回合 |
| 炸毁雷达 | 该阵营侦查范围-50% | 2回合 |
| 炸毁桥梁 | 两阵地间通行阻断 | 直到修复 |
| 刺杀军官 | 敌方随机一支部队军衔-1级 | 永久 |
| 窃取科技 | 获得敌方一项已研发科技 | 永久 |
| 营救战俘 | 获得一支随机部队 | 即时 |
| 标记目标 | 下次对该阵地攻击+30% | 1回合 |

## 残局保护机制

### 触发条件
系统评估双方实力差，超过阈值自动触发：
- 领土比 > 3:1
- 兵力比 > 2.5:1
- 经济比 > 3:1

### 劣势方保护（持续5回合）
| 保护项 | 效果 |
|--------|------|
| 停战保护 | 敌方不能主动进攻己方阵地 | 3回合 |
| 经济援助 | 每回合额外+30%收入 | 5回合 |
| 应急征兵 | 立即获得3支民兵+1支步兵 | 即时 |
| 防御加成 | 所有阵地+20%防御 | 5回合 |
| 情报屏蔽 | 敌方看不到己方部队部署 | 3回合 |

### 优势方补偿（征服者加成）
避免优势方觉得被系统针对：
- 占领速度+20%
- 战后掠夺资源+30%
- 历史时刻CG触发概率提升
- 获得"征服者"称号（声望加成）

### 新手保护
- 第一局必不匹配到残局
- 前3局匹配残局概率降低80%
- 匹配到残局时额外+1回合保护

## 时间流速平衡

### 三阶时间流速（已有设计）
| 档位 | 回合时长 | 适用场景 |
|------|---------|---------|
| 季度 | 90天/回合 | 和平期、长期经营 |
| 周 | 7天/回合 | 常规战争 |
| 四小时 | 4小时/回合 | 激烈战斗、FPS任务期间 |

### FPS任务期间的处理
- 策略层自动切换到"四小时"档（最快）
- 策略玩家有更精细的操作粒度
- 特遣队任务通常在2-5个"四小时"回合内完成
- 任务结束后自动恢复到之前的时间档位

### 策略玩家不等待
- 异步任务意味着策略玩家**不需要等**FPS玩家打完
- 可以继续经营、移动部队、发起其他任务
- 同一回合可同时有多个特遣队任务在进行
- 任务完成时通过通知面板提醒，不打断当前操作

---

## 特遣队玩家体验保障

### 不会没任务做
- 即使没有策略玩家发悬赏，也有"系统生成任务"（PVE任务）
- 自由行动模式随时可用
- 训练关卡可以练习技术

### 不会被当工具人
- 任务是悬赏制，可接可不接
- 有独立的成长线和装备系统
- 完成任务有成就感和实质奖励
- 可以影响战争走向（炸仓库→改变经济平衡）

### 匹配速度
- 特遣队任务短（5-15分钟），流转快
- 多个策略局同时发布任务，任务池充足
- 可跨局接任务（打完一局的任务，去另一局打）
